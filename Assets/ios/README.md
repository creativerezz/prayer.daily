# pray.daily for iPhone

Native SwiftUI app for iOS 17 and later. Today, Fasting, and Settings use the same tested Store, prayer service, local preferences/cache, and notification scheduler as the Mac app. No account is required.

## Build

Open `PrayDaily.xcodeproj`, select the `pray.daily` scheme, and choose an iPhone or simulator. Automatic signing uses the existing Reza Jafar team. Bundle ID: `com.reza.praydaily`. App Store Connect app ID: `6816553437`.

`Assets/ios/project.yml` is the source of project settings. After changing it, run `xcodegen generate --spec Assets/ios/project.yml` from the repository root.

Use an Xcode version Apple currently accepts for TestFlight, including a supported beta when listed in Apple's App Store Connect release notes. Set `DEVELOPER_DIR` per command if multiple versions are installed; changing the global selection is unnecessary.

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project Assets/ios/PrayDaily.xcodeproj -scheme pray.daily \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath .build/distribution/pray.daily.xcarchive \
  -allowProvisioningUpdates archive
xcodebuild -exportArchive \
  -archivePath .build/distribution/pray.daily.xcarchive \
  -exportOptionsPlist Assets/ios/UploadOptions.plist \
  -exportPath .build/distribution/Upload -allowProvisioningUpdates
```

Or run the whole pipeline from the repository root with `./testflight.sh release --group "Personal testing" --invite someone@example.com` (add `--dry-run` to print it first); `./testflight.sh invite --group NAME EMAIL...` invites without building. Waiting for processing and invites need an App Store Connect API key in `ASC_KEY_ID`/`ASC_ISSUER_ID`.

`Assets/ios/UploadOptions.plist` uploads for internal TestFlight testing. `Assets/ios/ExportOptions.plist` exports a distribution IPA locally. Neither submits an App Store release. Increment `CURRENT_PROJECT_VERSION` before subsequent accepted uploads.

## Assets and privacy

The opaque 1024px icon and launch mark are in `PrayDaily/Assets.xcassets`; source artwork and its generation prompt are in `../Brand`. Light/dark colors support both appearances. Original alert tones live in `../../Resources/Sounds` and are generated by `../../scripts/generate-sounds.py`. `PrivacyInfo.xcprivacy` declares UserDefaults and location use. Only OS-provided HTTPS encryption is used.
